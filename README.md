แพลตฟอร์มวางแผนทริปขับรถยนต์และขี่มอเตอร์ไซค์ทั่วไทยครบ **77 จังหวัด** ในรูปแบบแอปมือถือ (Mobile-First UI) สำหรับแก๊งเพื่อน

## ✨ ฟีเจอร์หลัก
- **เส้นทางถนนหลวงจริง 77 จังหวัด**: คำนวณระยะทางจริง รองรับเริ่มจาก GPS ปัจจุบัน และปุ่มสุ่มจังหวัดวัดใจแก๊ง
- **คำนวณค่าน้ำมันวันนี้ & หารงบทริป**: อ้างอิงราคาน้ำมันหน้าปั๊มไทย ปรับตามอัตราสิ้นเปลืองและจำนวนคนหาร
- **ปั๊มน้ำมันริมเส้นทาง & คำนวณระยะถัง**: สแกนปั๊มหลักตามกิโลเมตรจริง พร้อมแนะนำจุดแวะเติมตามขนาดถังรถ
- **แนะนำ 10 ที่เที่ยวตามสไตล์แก๊ง**: พร้อมภาพสถานที่จริง ข้อมูลที่จอดรถ เวลาเปิด-ปิด และส่งนำทางเข้า Google Maps / ไฟล์ `.GPX`
- **ศูนย์บัญชาการทริปแก๊ง**: คำนวณเวลานัดล้อหมุน-ถึงปลายทาง, เบอร์ฉุกเฉินกดโทรออกทันที (`1193`, `1669`), หารบิลส่งกลุ่ม Line, เช็กลิสต์ก่อนออกรถ และสภาพอากาศสด + PM2.5
